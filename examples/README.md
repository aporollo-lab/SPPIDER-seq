# SPPIDER-seq Prediction Examples

This folder contains example inputs and outputs illustrating the use of **SPPIDER-seq** for partner-aware protein–protein interaction (PPI) site prediction. The examples focus on **human TP53** and demonstrate how predicted PPI sites depend on the identity and role of the interacting partner.

In these examples, TP53 is evaluated in two distinct interaction contexts:

1. **As a ligand**, interacting with **CCNA2** and **MDM2**
2. **As a receptor**, interacting with **TP53BP1**

These cases highlight the context-specific nature of PPI site prediction captured by SPPIDER-seq.

---

## Experimentally determined TP53 PPI sites

For reference and biological validation, experimentally determined TP53 interaction sites were derived from available PDB structures for each interaction partner, as summarized below.

### TP53–CCNA2

* **PDB entry:** 1H26 (chains E–B)
* **TP53 PPI sites:**
  S378, R379, H380, K381, K382, L383, F385, K386

### TP53–MDM2

* **PDB entry:** 1YCR (chains B–A)
* **TP53 PPI sites:**
  E17, T18, F19, S20, L22, W23, L25, L26, P27, E28, N29

### TP53–TP53BP1

* **PDB entry:** 1KZY (chains A–C)
* **TP53 PPI sites:**
  Q165, Q167, H168, E171, R174, P177, H178, R181, M243, G244, N247, R248, R249

These residues provide ground truth for interpreting and benchmarking SPPIDER-seq predictions.

## Contents of the `data` folder

The `data` subfolder contains both input files used to run SPPIDER-seq and the corresponding prediction outputs.

### FASTA files (`*.fasta`)

FASTA files define the sequences used as inputs to SPPIDER-seq:

* The **query protein** (TP53)
* Its corresponding **interaction partners** (CCNA2, MDM2, or TP53BP1)

These files are directly supplied to the SPPIDER-seq prediction pipeline.

### Prediction output archives (`*.zip`)

Each ZIP archive contains the full set of outputs generated by SPPIDER-seq for a given TP53–partner pair, including:

* `*.txt` files with **per-residue PPI probabilities**, reported separately for:

  * TP53 acting as a **ligand** or as a **receptor** (example 1)
  * The same probabilities annotated with **statistical significance**, assessed using null-background distributions (example 2)

* `*.png` files with **graphical plots** visualizing residue-level PPI probabilities along the TP53 sequence, with or without significance overlays.

Together, these files provide a complete, reproducible illustration of SPPIDER-seq predictions and their interpretation in biologically well-characterized TP53 interaction contexts.
