# SPPIDER-seq Prediction Examples

This repository contains example input and output files illustrating the
use of **SPPIDER-seq** for partner-aware protein--protein interaction
(PPI) site prediction. The examples demonstrate two biologically
distinct applications of SPPIDER-seq:

1.  **Human TP53** acting as a ligand in complex with **Cyclin A2
    (CCNA2)**.
2.  **Saccharomyces cerevisiae** mating pheromone α precursors
    interacting with their cognate receptor **Ste2**.

Together, these examples illustrate the ability of SPPIDER-seq to
predict interaction interfaces for both eukaryotic protein domains and
short bioactive signaling peptides embedded within larger precursor
proteins.

------------------------------------------------------------------------

# Example 1. Human TP53--CCNA2 interaction

This example demonstrates ligand-centric prediction of interaction sites
in the intrinsically disordered C-terminal regulatory region of the
human tumor suppressor **TP53** when bound to **Cyclin A2 (CCNA2)**.

## Experimentally determined TP53 PPI sites

-   **Interaction partner:** CCNA2
-   **PDB entry:** **1H26** (chains E--B)
-   **TP53 interface residues:** S378, R379, H380, K381, K382, L383,
    F385, K386

These residues provide the ground truth for interpreting the
accompanying SPPIDER-seq predictions.

# Example 2. Yeast mating pheromone α precursor--Ste2 interaction

This example demonstrates one of the unique applications of SPPIDER-seq:
identifying receptor-binding pheromone sequences **within complete
propheromone precursors**.

Unlike approaches that require mature peptide sequences as input,
SPPIDER-seq can analyze the entire precursor protein and correctly
localize the receptor-binding α-factor peptides after secretion and
proteolytic maturation. This capability makes SPPIDER-seq well suited
for discovering previously unannotated fungal propheromone genes and
identifying their functional pheromone regions.

## Interaction partner

-   **Ste2 receptor**
    -   UniProt: **D6VTK4** (*STE2_YEAST*)

## MFα1 precursor (UniProt: P01149 *MFAL1_YEAST*)

Contains four mature α-factor peptides:

- **90–102** — Mating factor α
- **111–123** — Mating factor α
- **132–144** — Mating factor α
- **153–165** — Mating factor α

## MFα2 precursor (UniProt: P32435 *MFAL2_YEAST*)

Contains two mature α-factor peptides:

- **87–99** — Mating factor α-like
- **108–120** — Mating factor α

The accompanying FASTA files contain both the **complete propheromone
precursor sequences** and the corresponding **mature α-factor peptide
sequences**. Including both enables users to (i) observe how SPPIDER-seq
localizes the functional pheromone regions within the precursor proteins
and (ii) directly compare the predictions made for the mature peptides
with the experimentally defined functional sequences.

# Contents of the `data` folder

The `data` subfolder contains both the input files used to run
SPPIDER-seq and the corresponding prediction outputs.

## FASTA files (`*.fasta`)

The FASTA files include:

-   complete precursor protein sequences;
-   corresponding mature α-factor peptide sequences (where applicable);
-   interaction partner sequences.

These files can be supplied directly to either the Google Colab notebook
or the command-line version of SPPIDER-seq.

## Prediction output archives (`*.zip`)

Each ZIP archive contains the complete prediction results generated by
SPPIDER-seq for the corresponding interaction pair, including:

-   per-residue PPI probabilities (`*.txt`);
-   graphical probability profiles (`*.png`).

Together, these examples demonstrate both conventional protein--protein
interaction prediction and the localization of functional signaling
peptides within larger precursor proteins.
